# The Honeypot Garden

Sister to the Dirty Hoe Cafe. A walled working garden staffed by women who garden seriously. Most dominate; a few switch or submit. Every character is 21 or older.

Each folder holds four files: `(LIL).json`, `(Soulkyn).md`, `(Profile).html` (Soulkyn rich profile), and `(LIL Mini App).html` (Vorm template, banner placeholder marked SWAP). Bots 02 onward are generated from `build.py` with the shared builder in `_tools/hg.py`, which also checks lengths, dashes, and banned phrases. Run `python3 build.py` in a folder to rebuild it.
