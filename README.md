# Bots
## library/

Backup of every bot, one folder per bot under its world: `library/<World>/<Bot>/`.

- `<Bot>.md`: main file with the canon from the most complete version, plus links to each site version
- `<Bot> (<Site>).md`: readable copy of that site's latest version (LIL, Soulkyn, Aksho, Character Card, Dream Journey, Companion, Notes)
- `raw/`: original exports as downloaded; `raw/older/` holds earlier distinct versions

The same markdown lives in OneDrive at `3 Resources/AI Characters` for Obsidian. Placeholder Aksho cards with no content are listed in `library/_Placeholders.md`.
